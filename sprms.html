🧮 Composite Score Formula
Score = (Skills × 0.4)
      + (Workshops × 0.3)
      + (Internships × 0.2)
      + (Projects × 0.1)
Each component is normalized to a 0–100 scale. The weighted sum is stored in a Max-Heap for O(log n) insertion and O(1) top-student retrieval.

Workshop attendance multiplies skill score by a bonus factor (1.05–1.25) based on relevance to career track.

How It Works

End-to-end flow from student data entry to placement-ready rankings and personalised recommendations.

🔄 System Flow
1

Data Ingestion

Student profiles, skill certifications, workshop attendance, and internship records are submitted via REST API. Each entry is validated and stored in PostgreSQL.

2

Skill Hashing

Skills are indexed into a HashMap keyed by Student ID. O(1) lookup enables instant profile retrieval during live placement drives.

3

Score Computation

The composite score formula weighs skills, workshops, internships, and projects. Scores are inserted into a Max-Heap in O(log n) time.

4

Graph Construction

A directed skill prerequisite graph is built from the curriculum ontology. BFS generates the personalised learning path for each student from their current skill node.

5

Path Optimisation

Dijkstra's algorithm computes the minimum-cost upskilling path to a target role, recommending the most efficient workshop sequence.

6

Dashboard & Alerts

Real-time rankings, individual feedback, and institutional analytics are surfaced via the React dashboard. Automated alerts notify students of skill gaps and upcoming workshops.
